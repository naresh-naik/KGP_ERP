Advanced: use the Gmail API instead (optional)

Only needed if the automatic method above does not work for you. It requires your own Google OAuth client ID.

  1. Open Google Cloud Console and create a project.
  2. In APIs & Services → Library, enable the Gmail API.
  3. In Google Auth Platform → Audience, choose External, keep it in Testing, and add your own Gmail address as a test user.
  4. In Clients → Create client, pick application type Chrome Extension and enter this Item ID:
  5. Copy the client ID into manifest.json in place of YOUR_CLIENT_ID.apps.googleusercontent.com, then reload KGP_ERP on the extensions page.
